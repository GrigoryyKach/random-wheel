# Random Wheel

Колесо фортуны для Windows: впишите участников справа, нажмите «Крутить колесо» — и программа выберет победителя.
Написано на Rust (eframe/egui), один exe без зависимостей, работает офлайн.

Оформление повторяет Smart Switcher (`../smart_switcher/src/settings/styles.css`): те же цвета светлой и тёмной темы,
фирменный градиент `#4f6bff → #8a5bff`, шрифт Segoe UI, карточки, переключатели и заголовки секций капсом.
Тема выбирается по системной.

## Запуск

```bash
cargo run --release
```

Готовый exe: `target/release/RandomWheel.exe`, его можно скопировать куда угодно.

## Что умеет

- **Колесо и список.** Переключатель «Список / Колесо» над колесом. В режиме списка выбор показывается бегущей подсветкой.
- **Участники** вводятся в поле справа, по одному на строку. Пустые строки пропускаются.
- **Обзор…** загружает список из `.txt` (строка — участник) или `.csv` (первый столбец; разделители `,` `;` или табуляция).
  Кодировки UTF-8, UTF-16 и Windows-1251, так что подойдёт и CSV из русского Excel.
- **Перемешать** и **А→Я** — порядок секторов на колесе.
- **Текст при победе** — своя фраза в окне результата, например «Сегодня дежурит…».
- **Длительность вращения** от 2 до 12 секунд.
- **Удалять после выбора** — победитель убирается из списка, когда закрываете окно результата.
  Без этой опции в окне есть кнопка «Убрать из списка».
- **Конфетти** при объявлении победителя.
- **История** последних 15 победителей.
- **Полноэкранный режим** — кнопка рядом с переключателем или F11, выход — Esc.

Горячие клавиши: Пробел или Enter — крутить (когда курсор не в поле ввода); в окне результата Enter, Пробел или Esc — закрыть.
Можно также просто щёлкнуть по колесу.

## Честность выбора

Победитель выбирается до начала анимации, равновероятно среди всех участников
(SplitMix64 с засевом от времени и системного `RandomState`, без смещения по модулю).
Анимация только доводит колесо до выбранного сектора; место остановки внутри сектора тоже случайное.

## Где хранятся настройки

`%APPDATA%\Random Wheel\config.json` — список участников, настройки, история. Сохраняется автоматически.

## Устройство

```
src/main.rs    окно, иконка (рисуется кодом)
src/app.rs     состояние, розыгрыш, главная область, панель настроек, окно победителя, конфетти
src/wheel.rs   генератор случайных чисел, математика вращения, отрисовка колеса
src/theme.rs   палитра и компоненты в стиле Smart Switcher: кнопки, переключатель, слайдер, значки
src/import.rs  чтение .txt/.csv и определение кодировки
src/config.rs  config.json
```

`theme.rs` не зависит от остального кода, его можно взять как общий модуль для будущего лаунчера.

## Тесты

```bash
cargo test
```

Для ручной проверки анимации в debug-сборке есть переменная `RANDOM_WHEEL_AUTOSPIN=1`:
колесо закрутится само через секунду после запуска.

## Обновления и NIMVORO

Утилита входит в набор [NIMVORO](https://github.com/GrigoryyKach/nimvoro): лаунчер ставит её в один клик и обновляет.
При запуске программа проверяет последний [релиз](https://github.com/GrigoryyKach/random-wheel/releases/latest) (переключатель «Проверять при запуске» в разделе «Обновления»).
Если есть новая версия, кнопка «Обновить» передаёт обновление лаунчеру, а без лаунчера открывает страницу релиза.

Релиз собирается GitHub Actions при пуше тега: поднимите версию в `Cargo.toml`, затем `git tag v{версия} && git push --tags`.
